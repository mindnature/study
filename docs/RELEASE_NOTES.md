# 知学 Agent v1.0.0

面向 WorkBuddy、Codex 等支持 Agent Skills 的中文学习辅助 Skill。

**面向普通用户：** 无需 Docker、Python、Node.js 和独立的 DeepTutor 安装。让智能体读取本仓库 SKILL.md、导入技能目录，即可通过自然语言尝试使用。现有宿主模型可能按其原有计划产生费用。

**核心能力：** 一次一题、基础诊断、分级提示、错因识别、独立测评、变式迁移、延迟复习、教材来源约束。经用户明确授权后，能够利用宿主文件工具写入可恢复的学习档案；有 Python 的宿主还可选择无需第三方包的原子写入工具。

**与 DeepTutor 的关系：** 这是独立的学习 Skill，借鉴面向掌握的教学思路；**不包含 DeepTutor 官方 Mastery Path 算法，也没有内置原版 RAG 或模型服务**。若本机另外配置了 DeepTutor CLI，可选调用原版功能。

**验证：** 自动化测试覆盖学习记录读写、状态推导、幂等写入及安装 ZIP 结构，使用 Linux 和 Windows CI 构建。仍需在实际 WorkBuddy/Codex 客户端逐项验证模型遵循教学指令的效果；CI 成功不代表用户行为百分之百通过。

**升级：** 由 V0.1/V0.2 升级时先备份旧 Skill。旧格式学习数据不会自动覆盖或迁移。安装或更新 Skill 不会修改已有学习记录。
