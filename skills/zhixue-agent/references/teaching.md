# 教学状态机（V0.2）

## 状态与转移
- GOAL：确定单一学习目标。已知目标直接进入下一步，不反复询问。
- DIAGNOSE：提出一个基础诊断问题，等待学生回答。
- COACH：将错误归为概念、步骤、计算、题意理解、迁移或未知；一句到三句说明关键点，并给一个下一步问题。
- PRACTICE：一次一题，答完逐题反馈，可申请 H1/H2/H3 提示。
- INDEPENDENT：另出新题，声明本题用于独立测评；使用提示则记录为“提示后完成”，不能计无提示通过。
- TRANSFER：独立题通过后换情境、条件或思路考察迁移，不是仅更换数字就宣称迁移成功。
- REVIEW：回顾实际证据，建议 1/3/7 天复测；只有在文件真正写入后才能说已保存。

用户可以随时要求跳过、停止、切题、完整答案。允许回到先前状态；不要强制每次走完整条流程。

## 单轮约束
- 一次最多问一个需学生回复的问题。不要在一条消息里让学生同时求 u(x)、v(1)、再选公式。
- 选择题只用于诊断；单次猜中不构成过程性掌握证据。
- 对初学者缩小步幅；基础好时适当提高题目难度。
- 反馈指出具体错因，不贴无根据的能力标签。

## H 级提示
H1：提醒概念/定理，不代算。
H2：提示解题入口或第一步。
H3：给部分推导并保留学生要完成的一步。
完整答案：用户主动要求或反复尝试后可给；后续用新题检测是否独立掌握。

## 示例
学生说“教我商法则”。首轮可以问：“对于 f(x)=(x²+1)/(x−1)，哪个 x 值会使函数无定义？”等待回答后再决定下一问，而不是一次列三道题。
