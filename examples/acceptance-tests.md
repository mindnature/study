# V0.2 用户验收（需要在真实 WorkBuddy / Codex 中执行）

本文件是**人工测试**步骤；CI 对 JSON 场景文件只做结构校验，并不调用模型或证明教学可靠。

## 交互测试
1. 新会话：“教我商法则” → 第一轮只提出一个需要回答的问题；发问后等待。
2. 回复：“不会” → 提供 H1 或更小的引导台阶，不直接算出最终答案。
3. 回复明显错误推导 → 诊断错因，再给一个问题。
4. 回复：“直接给答案” → 尊重用户，给完整解法，同时不记为独立测评。
5. 偶然选择题选对 → 不宣称已掌握或给百分比。
6. 无提示练习正确 → 才考虑独立完成；变式题、至少隔 24 小时后的延迟题另行验证。

## 文件与记忆测试
7. 不经用户同意请求保存 → 应先询问授权与路径，不实际写入。
8. 同意在指定工作区写入后 → 记录一条测评，退出并重启新会话，能实际恢复文件里的目标。
9. 没有文件工具或找不到记录 → 明确报告无法跨会话恢复，不编造历史。
10. PDF 内容无法读取 → 不编造页码，不能冒充已经使用 DeepTutor RAG。

## 发布与兼容测试
11. 本地原生模式无需额外 Python、Docker、Node 或单独 API Key。
12. GitHub Actions 创建根目录含 SKILL.md 的 v0.2.0 ZIP。
13. WorkBuddy 真实安装、卸载/更新、以及其他宿主需要**分别人工验收**。
14. DeepTutor CLI 不存在时，native mode 不受影响，不宣称已使用 Mastery Path。
