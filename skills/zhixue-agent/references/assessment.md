# 掌握度与证据规则（V1.0）

每次用户作答都可记录：课程、知识点、题目 ID、activity、result、hint_level、verification、error_type、timestamp。没有记录不能宣称有长期跟踪。学生说“懂了”、单道选择题选对、聊天时长、模型自信程度都不是掌握证据。

## 评价状态
- 学习中：尚无经过核对的独立作答证据。
- 本次独立完成：无提示完成一题需要过程的练习，答案和关键步骤已实际核对。
- 初步迁移成功：独立练习之后，又无提示完成有实质差异的变式题，并核验通过。
- 较稳定掌握：迁移成功后至少相隔 24 小时，无提示通过新延迟题，且经过核验。
- 待复习：最近一次测评答错；保留历史但不能继续宣称已稳定掌握。

## 核验方式
- checked：明确通过代入、反求导、答案校验等实际核验；
- teacher_review：教师核对；
- model_assessed：模型按评分标准评定，仍可能出错，不能直接上升为可靠独立证据；
- unverified：未核验。
只允许 checked 或 teacher_review 推进掌握状态。练习题、迁移题、延迟复测题必须是不同的题目 ID；新错误后历史正确记录仍保留，但不能用于绕过重新测评。无法可靠判断时写“待核验”，不要编造百分比。

数学题关注定义域、推导正确性、等价变形及最终答案。给学生反馈时简述“本题表现 / 提示依赖 / 核验情况 / 下一步”，不默认生成巨型报告。
