# 升级到 V1.0

## WorkBuddy / Codex 升级
1. 先确认宿主 Skill 安装路径，备份原来的 zhixue-agent 文件夹和用户自己的学习档案。
2. 让智能体按 [INSTALL.md](../INSTALL.md) 从 GitHub 仓库或专用发布 ZIP 安装；只覆盖**技能文件**，不要覆盖用户工作区。
3. 重新加载 Skill，确认使用版本 1.0.0，并测试“一次一问”和“不会”时的提示行为。
4. 如果曾授权过本地学习记录，确认工作区路径仍有效。在新会话中让智能体实际读取档案；不能读取就如实说明。

## 旧学习数据
- V0.1 默认无跨会话保存；原有对话不会自动写入学习记录。
- V0.2 使用 schema_version 0.2.0，V1.0 继续使用这一格式，**不需要迁移记录数据**。
- 若以前依据 V0.1 progress.md 手动创建 schema_version 0.1.0 的档案，V1.0 工具会拒绝直接覆盖它。保留原始备份，再进行明确授权的字段迁移；目前没有自动无损迁移器。
- 学习记录中的提示和测评不代表模型实际具有教师认证；“已掌握”必须具备核验后的独立作答、迁移和延迟复测证据。

## 对普通用户的承诺
- 基础 Skill 不要求 Docker、Python、Node 或 DeepTutor。
- 不能保证宿主有可写文件工具；没有就不能跨会话自动保存。
- 不擅自创建定时提醒，不把普通宿主回答宣称为 DeepTutor 引擎执行。
- 卸载技能时应保留自己选择的 .zhixue 学习记录，除非用户另行同意删除。
