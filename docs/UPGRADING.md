# 从 V0.1 升级到 V0.2

## 最简升级
WorkBuddy 已安装 V0.1 的用户：先备份旧技能目录和自己已有的学习档案，再让智能体读取本仓库的新版 SKILL.md、references/ 与 scripts/，安装到其支持的技能目录，重新加载并在新会话中进行验收。**不要**覆盖任何用户选择的工作区、模型设置或其他 Skills。

## 用户数据不会自动迁移
- V0.1 默认只在聊天上下文中保持状态，通常没有独立历史文件；聊天历史不会自动导入 V0.2。
- 若用户依照旧版 progress.md 手工保存过 .zhixue/learning-records.json，则先备份；新版工具仅识别 schema_version=0.2.0。遇到 0.1.0 会拒绝写入，不会自动覆盖。
- 如需迁移，需要用户明确批准后进行字段映射、验证并保留原始备份；目前**未提供自动迁移器**。
- 本地脚本不提供自动后台提醒；仅输出建议的复习日期。

## 安装后验收
1. 在新的 WorkBuddy 会话询问“你加载的 Skill 路径是什么？”确认真正启用。
2. 说“教我商法则”，检查第一轮是否只提出一个问题。
3. 回复“不会”，检查是否给一个分级提示而非完整答案。
4. 明确授权后保存一条真实测评记录，重新打开对话再尝试读取；没有授权时不允许创建文件。
5. 验证不安装 Python/DeepTutor 时原生辅导仍能运行。

GitHub Actions 的成功只证明 ZIP 结构及测试脚本通过，不等于 WorkBuddy 不同版本已完成 UI 实测。
